# UX / Design Specification

## Design Principle
Modern, visual, calm and classroom-ready. The interface should help learning rather than compete with it.

## Navigation
Desktop: sidebar.
Mobile: bottom navigation for Home, Course/Chapters, Lab and Practice; secondary items in menu.

## Dashboard
```text
PHYSICS
Welcome back

CONTINUE LEARNING
Chapter → Topic
Progress
[ Continue ]

TODAY
Study time | Topics | Questions

NEXT UP
Recommended next topic

QUICK ACCESS
Chapters | Lab | Practice | PYQs | Formulas | Bookmarks
```

## Chapter Page
Chapter title, progress, Continue Learning, topic list with states, Practice, Chapter Test, Formula Bank and PYQs.

## Topic Page
Top: Back + position.
Main: lesson blocks.
Bottom: Bookmark + Continue.
Contextual More menu: Notes, Bookmark, Formula, Settings.
No giant toolbar.

## Learning Flow
Teaching → animation/demo → Formula/Derivation → Formula Lab where useful → MCQs → numericals → PYQ where relevant → mastery → next topic.

## Classroom Mode
Full-screen, large controls, high contrast/readability, minimal distractions:
`← Previous | Topic 4/12 | Next →`

Tutor can reveal questions, answers, explanations and solutions without being forced through student attempts.

## Textbook Viewer
Tutor-only. Previous/Next page, zoom and full screen. Touch-friendly for Windows Smart Boards. Page mappings are attached to relevant topic content.

## Visual Language
Use animation, diagrams, graphs and simulation only when they improve comprehension. Avoid decorative motion.

## Accessibility
Support dark/light, text sizing, reduced motion, sound controls, keyboard navigation, high contrast, touch targets and screen-reader structure.
