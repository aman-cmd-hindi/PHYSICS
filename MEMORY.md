# Project Memory / North Star

## Product
Maharashtra Board Physics learning + classroom platform covering all 16 chapters.

## North Star
A student can prepare a complete Physics chapter using their notebook and this website alone for normal learning.

## Core Principle
Every important concept should be taught, visualized, demonstrated, practiced and tested inside one learning flow.

## Locked Decisions
- 16 chapters, Rotational Dynamics → Semiconductor Devices.
- Chapter → Topic; no Core Concepts layer.
- Hybrid animated-slide/interactive lesson system.
- Integrated questions.
- MCQs in every relevant numerical section/topic.
- Guided → Semi-guided → Exam numericals.
- Formula Labs for important quantitative relationships where practical.
- Topic-wise immediate numericals.
- PYQs integrated plus dedicated PYQ section.
- Practice: topic/chapter/mixed + adaptive.
- Tests: chapter/multi-chapter/full/custom/adaptive.
- Revision: spaced, weak-topic, countdown and performance-based.
- Formula system: lessons + bank + labs + derivation practice + formula MCQs.
- Notes/bookmarks/highlights/saved formulas.
- Analytics: mastery, accuracy, numericals, tests, weak concepts, revision, trends.
- Universal search.
- No student-facing AI.
- Full accessibility.
- Hybrid offline + explicit chapter downloads.
- Complete Learning Operating System.
- Tutor uses same course but can freely navigate and reveal answers.
- Smart Board classroom mode.
- Tutor-only authorized textbook page viewer.
- No normal classroom workflow redirects.
- Admin Content Studio + ingestion + human verification + versioned publishing.
