# Product Rules — Locked Decisions

1. Guide strongly, but never unnecessarily trap the student.
2. The topic contains everything needed; no separate Core Concepts layer.
3. Opening a topic does not complete it.
4. Numericals appear immediately after the relevant topic.
5. MCQs are integrated into numerical/relevant learning sections.
6. Numerical progression is Guided → Semi-guided → Stage 3 Exam.
7. Wrong answer → hint/retry → explanation → worked example if needed → retry → continue.
8. Correct answers receive confirmation and explanation.
9. Completed topics can always be revisited.
10. Chapter completion requires topic mastery plus Chapter Test.
11. Maharashtra Board conventions are authoritative.
12. Use the simplest visual that improves understanding.
13. Important derived quantitative relationships should have a Formula Lab where practical.
14. Questions appear at pedagogically useful points, not constantly.
15. Controls are contextual and appear only when useful.
16. No AI on the student-facing web platform.
17. Optional AI may assist admin-side drafting only.
18. AI drafts require human verification before publication.
19. Published content is versioned.
20. Tutor uses the same course, with free navigation and answer/solution reveal.
21. Tutor gets authorized exact textbook-page reference inside the site.
22. Normal classroom learning should not require external redirects.
23. Bookmarks are required.
24. Local progress works without login; cloud sync is optional.
25. Accessibility is built in from the beginning.
26. Offline progress and synchronization must be predictable.
27. Student dashboard prioritizes Continue Learning.
28. Topic state is Completed / In Progress / Not Started.
29. Revisit, retake and weak-topic recovery are first-class flows.
30. Content updates must not destroy valid student progress.
