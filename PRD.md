# Maharashtra Board Physics Platform — PRD

## 1. Product Vision
A complete digital Maharashtra Board Physics course and classroom platform covering all 16 chapters, from Rotational Dynamics through Semiconductor Devices.

**North Star:** A student should be able to prepare a complete chapter using only their notebook and this website for normal learning.

## 2. Users
- Student: guided sequential learning, practice, mastery, revision and testing.
- Tutor: same course content, but with free navigation and immediate answer/solution reveal.
- Admin/Content Manager: create, verify, version and publish official course content.

## 3. Core Structure
Physics → Chapter → Topic → integrated lesson, visuals, Formula Lab, questions, numericals and relevant PYQs → mastery → next topic → Chapter Test.

No separate Core Concepts layer.

## 4. Student Experience
- Continue Learning resumes the exact saved position.
- Topic flow: teaching → visual/demonstration → formula/derivation → Formula Lab where useful → MCQs → numericals → PYQs where relevant → mastery.
- Numericals occur immediately after the relevant topic.
- Guided → Semi-guided → Stage 3 Exam numerical.
- Wrong answers trigger hint/retry and explanation paths.
- Completed topics remain revisitable.

## 5. Question System
Integrated:
- Check Your Understanding
- Topic Practice
- Numerical Challenge MCQs
- Topic/PYQ questions
- Chapter Tests
- Multi-chapter, full-syllabus, custom and adaptive tests.

## 6. Mastery
Opening a topic never marks it complete.
Learning → Practice → Minimum mastery → Topic completed.
All required topics + Chapter Test = Chapter Complete.

## 7. Tutor/Classroom Mode
Tutor uses the same core course with:
- free navigation
- Show Question / Answer / Explanation
- reveal solutions
- presentation/full-screen mode
- simulation controls
- large Smart Board controls
- tutor-only textbook page reference and in-site viewer.

The platform should follow a **No Redirect Principle** for normal classroom teaching.

## 8. Content
Content is syllabus-complete rather than page-by-page textbook reproduction. Maharashtra Board notation, terminology, units, signs, derivations and diagram conventions are authoritative.

Pipeline:
verified sources → optional admin-side AI draft → human verification → Content Studio → preview → approval → publish/version.

## 9. Accessibility
Dark/light mode, font sizing, reduced motion, sound controls, full screen, keyboard navigation, high contrast, touch-friendly controls, accessible graphs/simulations and screen-reader-friendly structure.

## 10. Offline
Hybrid offline system:
- local cache
- offline progress
- optional chapter download
- automatic sync after reconnection
- predictable conflict handling.

## 11. Analytics
Topic mastery, chapter progress, MCQ accuracy, numerical performance, test scores, weak concepts, revision status and trends. Keep the UI simple.

## 12. Search
Universal search across concepts, topics, formulas, derivations, numericals, MCQs, PYQs, diagrams, simulations, notes and bookmarks.

## 13. Non-Goals
- No student-facing AI chatbot/tutor.
- No tutorial-video library.
- No dependency on PPTs.
- No unnecessary external redirects.
